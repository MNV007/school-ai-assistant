# Contributing

Thanks for helping improve SchoolAI Assistant.

## Good first contributions
- Report a reproducible bug or suggest a small improvement.
- Improve setup instructions or accessibility.
- Add tests for text templates and input validation.
- Propose privacy and safety improvements.

## Guidelines
- Do not commit real student, parent, or staff personal data.
- Do not commit API keys, credentials, private school documents, or photos of children.
- Keep pull requests focused and explain what changed and how it was checked.
- AI-generated code should be reviewed and tested by the contributor.
- Robot-control work must not bypass hardware safety mechanisms or adult supervision.

## Development
This is a static HTML/CSS/JavaScript demo. Open `index.html` in a browser and test the forms and tabs. Run `node --test` to check the text templates.
